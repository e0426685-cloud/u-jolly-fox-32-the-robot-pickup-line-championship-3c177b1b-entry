An entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on [make.fun](https://make.fun): one pickup line, a single line of at most 200 characters, in the voice of a robot trying to charm someone.

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the entry line to `/output/entry.txt` and enforces the competition gate: UTF-8 text of 1 to 200 characters, not only whitespace, a single line.
